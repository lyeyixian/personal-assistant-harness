# Triage Labels

The skills speak in terms of five canonical triage roles. This repo only carries two of them as
actual labels — issues here are filed already scoped rather than triaged from a backlog, so
`needs-triage`, `needs-info`, and `ready-for-human` have never been needed. This file maps the
roles actually in use to the label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | --------------------- | ----------------------------------------- |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `wontfix`                  | `wontfix`             | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label
string from this table. If a skill needs `needs-triage`, `needs-info`, or `ready-for-human`, create
the label first and add it here.
